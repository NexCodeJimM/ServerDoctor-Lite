ServerDoctor Lite — Permissions & Commands Reference
Version: 0.9.2-BETA
Base command: /doctor

Tab completion shows only subcommands the sender has permission to use.
Console: all commands work from console except /doctor tpchunk (players only).

================================================================================
NEW IN 0.9.2-BETA
================================================================================

INVESTIGATION SESSIONS (serverdoctor.investigate — default: op)
  /doctor investigate start     Start a troubleshooting session (tracks spikes, samples, chunks, cleanup)
  /doctor investigate stop        Stop the active session (short summary)
  /doctor investigate status      Active session progress and live counters
  /doctor investigate summary     Full advisory session summary

PERFORMANCE BASELINE (serverdoctor.baseline — default: op)
  /doctor baseline create         Save snapshot to plugins/ServerDoctor/baselines/default.yml
  /doctor baseline compare        Compare current metrics vs baseline (improved / stable / degraded)
  /doctor baseline status         View saved baseline details
  /doctor baseline delete         Warn before removal (does not delete yet)
  /doctor baseline delete confirm Permanently remove the saved baseline file

================================================================================
QUICK STAFF SETUP (LuckPerms / permission plugin examples)
================================================================================

Moderators (read-only diagnostics):
  serverdoctor.use
  serverdoctor.about
  serverdoctor.status
  serverdoctor.report

Admins (full ServerDoctor Lite):
  serverdoctor.*   (or grant each node above; all default op except use and about)

Investigation / baseline only (add to admin group):
  serverdoctor.investigate
  serverdoctor.baseline
