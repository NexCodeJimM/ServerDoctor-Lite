# Release folder (local use)

This folder is for **packaging builds before upload**. It is not part of the compiled plugin.

- **Do not commit `.jar` files** to Git (see root `.gitignore`).
- Upload release JARs to **GitHub Releases** or your resource site instead.

See [docs/RELEASE.md](../docs/RELEASE.md) for the full release workflow.

Example local layout:

```text
release/0.9.0-BETA/ServerDoctor-0.9.0-BETA.jar
```
